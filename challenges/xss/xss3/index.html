👋 个性化问候生成器

在 URL 上带上 ?name=你的名字，页面会在浏览器里为你生成问候。右键"查看网页源代码"——你会发现服务端根本不知道你叫什么。

问候

你好, 游客!
🔍 查看本题关键源码（页面 JS） 
var n = new URLSearchParams(location.search).get('name') || '游客';
n = n.replace(/<script[\s\S]*?>/gi, '');                    // 过滤：只删 <script ...> 开标签
document.getElementById('greet').innerHTML = '你好, ' + n + '!'; // sink：innerHTML
