让缓存替你说谎 —— 缓存投毒 & 请求走私

难度：高阶 进阶攻击面 离线模拟器

📖 题目描述

受害站点 /home 的统计脚本域名取自 X-Forwarded-Host 请求头， 而 CDN 缓存键只含路径（"未入键"头 = 缓存投毒的经典温床）。 攻击者只需带恶意头请求一次 /home，之后所有人都会拿到被污染的页面、 执行攻击者域上的 JS。完整走通：① 投毒 → ② 受害者访问 → ③ 攻击者日志里偷到的 Cookie（含 flag）。 第二条拿 flag 的路：在"修复挑战"里选对正确的 Nginx 配置——flag 就放在正确配置里。

🔌 为什么这一关是离线模拟器

缓存投毒的"受害者"是反代/CDN 缓存层，请求走私的成因是前后端两个解析器对同一字节流的分歧—— 两者都依赖反向代理拓扑，单层 PHP-FPM 无法保真复现。本关按 docs-static 先例（ssti5 / pp1）交付 静态教学页 + 前端离线模拟器：缓存键/缓存命中/投毒覆盖、CL 与 TE 两种切分视角， 全部在页面内用 JS 按原服务端（_original/app.py）的语义逐行复刻。
