说明

② 成功的链条：沙盒 iframe（无 allow-same-origin）→ 源=null → fetch 是跨源请求 → quote.php 反射 Access-Control-Allow-Origin: null → 浏览器放行"读" → 脚本拿到 JSON，postMessage 交给本页显示。

③ 失败的链条同理：fixed_quote.php 对 null 不发任何 CORS 头 → fetch 的响应是 opaque 的 → TypeError: Failed to fetch。这就是 SOP 正常工作的样子，也是"拒绝 null"的意义。
